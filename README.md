# Nightclub Empire

A stylised 3D isometric nightclub tycoon by MAGIX Development.

## First playable prototype
- Godot 4 project, Android-first
- Isometric 3D nightclub built from procedural meshes (no paid assets)
- Animated customers, DJ booth, bar and dance floor
- Passive cash income, customer satisfaction and reputation
- Upgrade buttons for the dance floor, bar and VIP lounge
- Local save/load using Godot's user data directory

## Open and run
1. Install Godot 4.3 or newer.
2. Import this repository's `project.godot`.
3. Press F6/F5 or the Play button.

## Android export
Install the Godot Android export templates and configure the Android SDK/JDK in Editor Settings. Then add an Android export preset and export an APK. The project is configured for portrait touch controls.

## Online mode
The first playable build is offline-first. Online multiplayer, accounts, cloud saves and leaderboards are planned for a later phase; they are not represented as working features in this prototype.

## Controls
- Tap the upgrade buttons to improve the club.
- Cash increases while the club is open.
- Tap SAVE to save progress.
- Tap OPEN/CLOSE to pause or resume club income.
